# show_foxes

Demonstration of a Quarto report layout (Celon Pharma template: title page, numbered sections and subsections, cross-references, one portrait and one full-page landscape table, separately numbered appendices, bibliography, table of contents and lists of tables and figures) filled with a fictional text on fox evolution. All data are simulated by `programs/fox_demo/run_analysis.R`, all references are invented, and the photographs are taken from Wikimedia Commons under the licenses stated in the captions. To reproduce, run `Rscript programs/fox_demo/run_analysis.R` from the repository root to create the figures and the data cache, then `quarto render reports/fox_demo/fox_demo.qmd` (PDF output requires XeLaTeX, the Calibri and Source Code Pro fonts and the `clreptcl` LaTeX class); the `required/` folder holds the `clreptcl.cls` class (copy it into a local `texmf` tree, e.g. `TinyTeX/texmf-local/tex/latex/local/`, and run `texhash`) and the Lua filters `no-split-table.lua` and `docx-para-normal.lua`; the rendered `fox_demo.pdf` and `fox_demo.html` are included in `reports/fox_demo/`.
